# Анализ предметной области

## Кандидаты в классы

| Кандидат | Что хранит | Что умеет |
|---|---|---|
| Книга (Book) | ISBN, автора, название, состояние, имя читателя | Проверять доступность, выдаваться и возвращаться |
| Библиотека (Library) | Список книг | Добавлять книги, выдавать и принимать их, показывать список |
| Читатель (User) | Имя читателя | Брать и возвращать книги |

ISBN, автор, название - данные книги, поэтому отдельные классы для них не нужны
читателя пока тоже можно не делать отдельным классом тк для задания достаточно хранить его имя у выданной книги

## Инварианты

1 ISBN у каждой книги уникален
2 Книга либо доступна, либо выдана
3 Выдать можно только доступную книгу
4 У доступной книги нет читателя, у выданной есть имя читателя
5 После возврата книга снова доступна
